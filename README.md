## 화면 구조 (v1.5)

하단 내비 5개 화면(운세 · 사주 · 번호 · 기록 · 멤버십)을 **탭 전환형**으로 보여 줍니다. 한 화면에 카드가 세로로 길게 쌓이지 않고, 실제로 선택한 카테고리만 표시됩니다.

- **사주** 화면 안에서 `내 사주 팔자 / 2027 신년 총운 / 분야별 운세 / 주의할 달` 4개 카테고리 칩으로 나눕니다. `분야별 운세`는 💰금전 · 💼사업·일 · 🌿건강 · 💞연애·가족 칩으로 한 분야씩, `주의할 달`은 ⚠주의할 달 · 🍀길한 달 칩으로 한 달씩 펼칩니다.
- **번호** 화면은 `오늘의 번호 / 이번 주 5조합 / 소원 부적 / 구매 길일`, **멤버십** 화면은 `요금제 / 정밀 10조합 / 심층 리포트 / 1년 캘린더 / 길일` 칩으로 나뉩니다.
- 인트로 스플래시·웹툰 점사 컷신·결제 게이트의 이동 버튼은 대상 화면과 카테고리를 자동으로 활성화한 뒤 스크롤합니다(`scrollIntoView` 가로채기 + 해시 `#saju` 등 지원).

## 웹툰 점집 (v1.3)

- 이용자 성별에 맞춰 점술사 캐릭터가 바뀝니다 — 여성은 점집 미소년 **하윤**, 남성은 미녀 점술사 **설아**.
- 사주를 넣고 번호를 받으면 웹툰 컷신이 열려, 오늘 일진·재물운·행운 숫자를 말풍선 타자기 연출로 순서대로 들려줍니다.
  (자동 재생 · 다음/이전 대사 · 성별 즉시 전환 · 캐릭터 부유/호흡 · 금빛 입자 연출)
- 앞부분에서 오늘의 운을 매력적으로 풀어 준 뒤, 결정적인 대목에서 **회원가입 → 무료 회원 요금제(월간·연간) → VIP** 순서로 자연스럽게 안내하며 회원가입·결제(계좌이체·이용권 코드) 모달로 바로 연결합니다.
- 이미지: `assets/teller-male.webp`(미소년), `assets/teller-female.webp`(미녀) — 한지 배경에 multiply 블렌딩으로 얹습니다.
- 문구·대사는 `webtoon.js`의 `rawLines()` / `ctaHtml()` 한 곳에서 관리합니다.

## 사주 계산 방식

- **년주**: 입춘(태양 황경 315°) 기준으로 해가 바뀝니다.
- **월주**: 24절기(입춘·경칩·청명…) 경계로 월이 바뀌고, 월간은 오호둔(五虎遁)으로 계산합니다.
- **일주**: 율리우스일 기반 60갑자 순환.
- **시주**: 12시진(30분 경계), 시간은 오서둔(五鼠遁)으로 계산.
- 절기 시각은 태양 황경을 직접 계산합니다(표준 저정밀도 태양 위치식). 한국천문연구원 발표 시각과 **±10분 이내**로 맞으며, 절기 경계일에 태어난 경우 하루 차이가 날 수 있습니다.
- 음양력 변환은 1900~2050년 한국 음력 데이터를 내장했습니다(`lunar.js`).
- 오행 수리는 하도낙서(河圖洛書) 기준입니다: 1·6 수, 2·7 화, 3·8 목, 4·9 금, 5·0 토.

## 번호 생성 방식

무료·황금 조합 모두 아래 요소를 섞어 만들고, 같은 날에는 같은 조합이 나오도록 날짜·사주를 씨앗으로 쓰는 결정적 난수를 사용합니다.

1. **부족 오행 보완** — 사주에서 가장 적은 오행의 끝수 번호
2. **오늘 일진** — 오늘 일진 지지의 오행 끝수 번호
3. **최근 회차 통계** — 최근 10회 미출현(콜드) / 최근 30회 다출(핫)
4. **일간 수리** — 내 일간 오행의 끝수
5. **균형** — 합계 100~175, 홀짝은 2:4에서 4:2 사이, 연속 2개 이하, 3개 구간 이상


## 회차 데이터 갱신

```bash
python3 scripts/fetch_lotto.py --rounds 100
```

- 2026년 개편된 동행복권 JSON API를 사용합니다.
  - `https://www.dhlottery.co.kr/lt645/selectPstLt645Info.do?srchDir=center&srchLtEpsd=<회차>`
  - `...?srchDir=older&srchCursorLtEpsd=<회차>` 로 10회씩 과거 수집
- 서버가 응답하지 않으면 **기존 `lotto.json`을 유지하고 종료 코드 1**로 끝납니다. 앱은 내장 폴백 데이터로 계속 동작합니다.
- GitHub Actions(`.github/workflows/update-lotto.yml`)가 매주 토요일 21:20(KST)에 자동 실행하고, 변경이 있으면 커밋합니다. 저장소 **Actions** 탭에서 수동 실행도 가능합니다.
- ⚠️ 동행복권은 해외·데이터센터 IP를 막는 경우가 있습니다. GitHub Actions 러너에서 접속이 막히면 스크립트는 **기존 데이터를 유지하고 실패(exit 1)** 로 끝나며, 앱은 정상 동작합니다. 이때는 국내 네트워크에서 `python3 scripts/fetch_lotto.py --rounds 100` 을 실행해 갱신하면 됩니다. (2026-11-27 저장된 100회는 국내 네트워크에서 수집)

## 채널 모드 — 웹(계좌이체) / 플레이스토어(무료·광고형)

플레이스토어 앱은 **무료·광고형**으로만 출시합니다(Google Play 결제 정책: 앱 안에서 소비되는 디지털 콘텐츠는 Play 결제만 허용). 웹 사이트의 계좌이체·이용권 코드 판매는 그대로 두고, **앱으로 접속할 때만 다른 모드**로 동작하도록 분리했습니다.

- **채널 판별** — `index.html`·`privacy.html`의 `<head>` 인라인 스크립트가 CSS·본 스크립트보다 먼저 돕니다.
  - `?channel=play` → `window.BOKCHAE_PLAY = true`, `sessionStorage.bokchae_play_channel = '1'` 저장, `<html data-channel="play">`
  - `?channel=web` → 저장값 삭제(웹 판매 화면)
  - 파라미터 없음 → 저장된 값 사용(기본 web)
- **플레이스토어 모드에서 바뀌는 것**
  - 계좌이체 안내(`.pay-intro`·`.bank-mini`)·이용권 코드 입력창(`#voucherTop`)·요금표(`#planList`)·결제 조건(`#termsBox`)·결제 모달(`#payModal`)·요금제 탭 → **CSS로 처음부터 숨김**(`account.js`에서도 렌더하지 않음)
  - `Membership.has()` → 콘텐츠 기능(`weekly5`·`newYear`·`annualReport`·`deepReport`·`tenCombos`·`luckyDay` 등)은 **전부 true**, 광고 관련(`noAds`·`goldInstant`)만 false → 하단 배너·3초 대기는 유지
  - `saveLimit()` → 0(무제한), `openPay()` → 결제창 대신 안내 토스트, `renderMy()` → 계정·알림만 표시(결제 문구 없음)
  - 하단 내비 `멤버십` → **`심층`** 으로 바꾸고, 멤버십 화면은 `정밀 10조합 / 심층 리포트 / 1년 캘린더 / 길일`만 남김(태그는 `무료 개방`)
  - 5조합 잠금 문구·광고 대기 모달 카피 → "잠시 후 열립니다" / "무료로 이용 중이에요" 톤(`app.js`의 `applyPlayUi`, `AD_TXT`)
  - 웹툰 점사는 무료·광고형 전용 대사(`HOOK.*.playOpen`)와 CTA(`ctaHtml` play 분기)를 사용해 요금제 멘트를 쓰지 않음
  - 3일 소원 부적 카드 → 만들기·원본 저장·공유 모두 무료(`wish.js`의 `PLAY` 분기, `#wishBuy`는 숨김)
  - 개인정보처리방침 → `?channel=play`에서 "스토어 앱은 모든 기능 무료, 결제 없음" 안내로 바꾸고 계좌이체·요금 문단은 웹 전용(`.web-only`)으로 분리
- **TWA** — `work/bokchae-twa`의 `twa-manifest.json`·`app/build.gradle` `launchUrl`이 `/k-lotto-fortune/?channel=play`입니다.
- 정적 자원 캐시 버전: `?v=22` / 서비스워커 `bokchae-lotto-v22`.

## 멤버십 · 요금제 (계좌이체 + 이용권 코드)

회원가입·로그인과 구독 등급을 넣었습니다. 유료 이용은 **계좌이체 결제**입니다 — 결제창에 입금 계좌(카카오뱅크 3333-06-3329778 · 예금주 이원철)와 금액이 나오고, 원클릭 **계좌 복사** 버튼을 제공합니다. 입금 확인 후 운영자가 **이용권 코드**를 보내면, 고객이 멤버십·결제창의 코드 칸에 입력하는 즉시 등급이 열립니다. 계정·구독 상태는 기기(localStorage)에만 남습니다.

- **코드 규칙**: `BC-<등급>-<무작위 3자><체크섬 2자>` (예: `BC-P-K7M2Q`). 등급은 P(복채 패스) · Y(1년 패스) · V(황금 사주 패스 월) · L(황금 사주 패스 평생) · W(3일 소원 부적). 체크섬이 맞지 않으면 거부되고, 등록한 코드는 같은 브라우저에서 다시 쓸 수 없습니다.
- 코드 발급은 `scripts/make_vouchers.py`(같은 체크섬 알고리즘)로 하고, 발급 목록은 저장소에 올리지 않습니다.
- 같은 등급 코드를 다시 넣으면 남은 기간 뒤에 이어 붙고, 다른 등급이면 남은 기간이 사라진다는 확인을 거칩니다. 자동갱신은 없습니다.
